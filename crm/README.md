# CRM на Google Apps Script

Простая CRM для заявок с сайта: заявки падают в Google Таблицу, работа с ними — в аккуратной панели.
Ничего не нужно платить и хостить.

## Что получится

- Все заявки с сайта автоматически попадают в таблицу.
- Панель CRM: счётчики (новые, сегодня, в работе, договоры, сумма договоров, сумма в работе),
  поиск, фильтр по статусу, смена статуса, сумма договора, ответственный, заметки,
  кнопки «позвонить», WhatsApp и Telegram, выгрузка в CSV.
- Кнопка «+ Добавить заявку» — чтобы завести обращение не с сайта: звонок, мессенджер,
  рекомендация, тендер.
- Уведомление о новой заявке на почту и/или в Telegram.

## Установка (10 минут)

### 1. Таблица и скрипт

1. Создайте Google Таблицу — например, «CRM ЛИДЕР».
2. В таблице: **Расширения → Apps Script**.
3. Удалите содержимое `Код.gs` и вставьте код из `Code.gs`.
4. Слева **Файлы → + → HTML**, назовите файл ровно `Panel`, вставьте содержимое `Panel.html`.
5. В начале `Code.gs` поменяйте настройки:
   - `PANEL_KEY` — любой случайный набор символов (нужен, только если открываете панель по ссылке);
   - `NOTIFY_EMAIL` — почта для уведомлений (можно оставить пустым);
   - `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` — если нужны уведомления в Telegram.
6. Сохраните. Обновите вкладку с таблицей — вверху появится меню **CRM «ЛИДЕР»**.
7. Меню → **Оформить лист заявок** (создаст лист «Заявки» с оформлением) и
   **Добавить тестовую заявку** — чтобы проверить.

### 2. Публикация приёма заявок

1. В редакторе скрипта: **Начать развёртывание → Новое развёртывание**.
2. Тип — **Веб-приложение**.
3. «Запуск от имени» — **От моего имени**.
4. «Кто имеет доступ» — **Все** (иначе сайт не сможет отправить заявку).
5. Скопируйте выданный URL вида `https://script.google.com/macros/s/.../exec`.

### 3. Подключение сайта

В файле `src/lib/site.ts` вставьте URL:

```ts
formEndpoint: "https://script.google.com/macros/s/ВАШ_ID/exec",
```

Пересоберите и задеплойте сайт:

```bash
npm run deploy
```

Готово — заявки со всех форм сайта пойдут в таблицу.

## Как открывать панель

**Способ 1 (рекомендуется).** В таблице: меню **CRM «ЛИДЕР» → Открыть панель**.
Доступ защищён доступом к самой таблице — делитесь ею с менеджерами через обычный доступ Google.

**Способ 2.** По ссылке с ключом:
`https://script.google.com/macros/s/ВАШ_ID/exec?key=ВАШ_PANEL_KEY`
Удобно открыть с телефона. Ключ обязательно смените на свой — по этой ссылке видны все заявки.

## Суммы и ручные заявки

Сумму договора можно вписать прямо в строке таблицы-панели — она сразу считается
в счётчиках «сумма договоров» (статус «Договор») и «в работе» (статусы «В работе»
и «КП отправлено»).

Кнопка **«+ Добавить заявку»** заводит обращение, пришедшее не через сайт.
В поле «Откуда обращение» — список: звонок, WhatsApp, Telegram, MAX, почта,
рекомендация, тендер, повторный клиент. Список меняется в константе `SOURCES`.

## Статусы

`Новая → В работе → КП отправлено → Договор` и `Отказ`.
Менять список можно в константе `STATUSES` в `Code.gs`
(после изменения выполните меню **Оформить лист заявок**).

## Если что-то не работает

- **Заявки не приходят.** Проверьте, что развёртывание — «Веб-приложение», доступ «Все»,
  и что в `formEndpoint` URL заканчивается на `/exec` (не `/dev`).
- **После правки кода ничего не изменилось.** Нужно сделать новое развёртывание
  (**Начать развёртывание → Управление развёртываниями → Изменить → Новая версия**).
- **Панель не открывается в таблице.** Обновите страницу таблицы и разрешите скрипту доступ
  при первом запуске.
