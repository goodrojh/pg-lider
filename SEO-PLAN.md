## 3. Структура многостраничника

Сейчас сайт одностраничный. Для поиска нужны отдельные страницы: **одна страница —
один запрос**. Ниже — целевая карта сайта.

### 3.2. Подуслуги (второй уровень, 12–18 страниц — главный источник трафика)

Низкочастотные запросы конвертируют лучше всего. Под каждую — отдельная страница.

**Под проектированием:**
- `/uslugi/proektirovanie-zdaniy/promyshlennye/` — проектирование промышленных зданий
- `/uslugi/proektirovanie-zdaniy/sklady/` — проектирование складов и логистических комплексов
- `/uslugi/proektirovanie-zdaniy/zhilye-doma/` — проектирование многоквартирных домов
- `/uslugi/proektirovanie-zdaniy/obshchestvennye/` — проектирование общественных зданий
- `/uslugi/proektirovanie-zdaniy/rekonstrukciya/` — проект реконструкции здания
- `/uslugi/proektirovanie-zdaniy/kapremont/` — проект капитального ремонта
- `/uslugi/proektirovanie-zdaniy/stadiya-p/` — разработка проектной документации стадии «П»
- `/uslugi/proektirovanie-zdaniy/rabochaya-dokumentaciya/` — рабочая документация, стадия «Р»
- `/uslugi/proektirovanie-zdaniy/bim/` — BIM-проектирование

**Под обследованием:**
- `/uslugi/obsledovanie-zdaniy/pered-rekonstrukciey/` — обследование перед реконструкцией
- `/uslugi/obsledovanie-zdaniy/avariynyh/` — обследование аварийных зданий
- `/uslugi/obsledovanie-zdaniy/3d-skanirovanie/` — 3D-сканирование и обмерные чертежи

**Под изысканиями:**
- `/uslugi/inzhenernye-izyskaniya/geodezicheskie/`
- `/uslugi/inzhenernye-izyskaniya/geologicheskie/`
- `/uslugi/inzhenernye-izyskaniya/ekologicheskie/`

**Под ОКН:**
- `/uslugi/okn/nauchno-proektnaya-dokumentaciya/`
- `/uslugi/okn/gike/` — государственная историко-культурная экспертиза
- `/uslugi/okn/prisposoblenie/` — приспособление памятника под современное использование

### 3.3. Разделы проектной документации (сильный ход под наше имя)

Название компании буквально совпадает с запросами «раздел проекта АР», «раздел КР»
и т.д. Это десятки низкочастотных запросов с хорошей конверсией.

`/razdely/` — обзор + по странице на раздел:
`ar`, `kr`, `ov`, `vk`, `eom`, `ss`, `pb`, `pos`, `oos`, `odi`, `ee`, `th`, `pzu`, `sm`

Шаблон страницы: что входит в раздел, по каким нормам, из чего состоит, сроки,
от чего зависит цена, частые замечания экспертизы, форма заявки.

### 3.4. География (после того, как заработают услуги)

- `/moskva/`, `/bryansk/`, `/orel/` — по офисам компании
- далее: `/proektirovanie-zdaniy-moskva/` и т.п. под региональные запросы

Важно: страницы городов делать с уникальным текстом и реальными объектами региона,
иначе это шаблонный спам и фильтр.

### 3.5. Объекты (портфолио)

- `/obekty/` — каталог с фильтрами
- `/obekty/<slug>/` — страница объекта: задача, что делали, сроки, результат,
  состав документации, фото. 21 объект уже есть — это 21 страница с уникальным текстом.

### 3.6. Остальное

- `/o-kompanii/` — о компании, лицензии, СРО, команда
- `/blog/` + 26 статей (есть)
- `/kontakty/` — контакты, карта, реквизиты
- `/czeny/` — стоимость и форматы работы
- `/politika-konfidencialnosti/`, `/soglasie-na-obrabotku/` — обязательны по 152-ФЗ

**Итого целевой объём: 70–90 страниц.** Это нормальный размер для выхода в топ
по коммерческим запросам в нише проектирования.

## 4. План по этапам

### Этап 0. Запуск домена — 1 неделя
1. Подключить `razdel-proekt.ru`, HTTPS, залить сайт (`npm run build:domain`).
2. Склеить зеркала: `www` → без `www`, `http` → `https`, один слеш на конце.
3. Яндекс.Вебмастер + Google Search Console, добавить sitemap.
4. Яндекс.Метрика + цели на все формы (у нас уже размечены `intent` у каждой формы).
5. Проверить индексацию служебных страниц, закрыть лишнее.

### Этап 1. Семантика — 1–2 недели
1. Собрать ядро: Яндекс.Вордстат + Key Collector/Арсенкин, 1500–3000 фраз.
2. Снять частотности и конкуренцию, убрать мусор (вакансии, обучение, рефераты).
3. Кластеризация по выдаче → каждый кластер = одна страница.
4. Зафиксировать карту «кластер → URL → H1 → Title → Description».

### Этап 2. Посадочные страницы — 6–10 недель
Порядок запуска по приоритету (трафик × конверсия × простота):
1. Обследование зданий — высокий спрос, мало сильных конкурентов.
2. Проектирование промышленных зданий и складов — наш главный опыт.
3. ОКН — узкая ниша, мало кто умеет, высокий чек.
4. Разделы документации — много НЧ-запросов.
5. Остальные услуги и города.

Каждая страница по единому шаблону:
- H1 с ключом, вступление 2–3 абзаца
- Что входит в услугу (список)
- Этапы работы со сроками
- Сколько стоит и от чего зависит
- 2–3 наших объекта по теме
- FAQ (5–7 вопросов → разметка `FAQPage`)
- Форма заявки с «интентом» этой страницы

**Объём:** 2500–5000 знаков уникального текста. Без воды и без «динамично
развивающаяся компания».

### Этап 3. Техническая оптимизация — параллельно
- [ ] Хлебные крошки с разметкой на всех страницах
- [ ] `FAQPage` на страницах услуг, `Service` на услугах, `Place`/`LocalBusiness` на городах
- [ ] OG-картинки для каждой страницы
- [ ] Страница 404 с навигацией
- [ ] Core Web Vitals: сейчас хорошо, следить после добавления страниц
- [ ] Перелинковка: услуга ↔ подуслуга ↔ объекты ↔ статьи

### Этап 4. Доверие и ссылки — постоянно
- Яндекс.Бизнес, 2ГИС, Google Business с фото и отзывами
- Профильные каталоги: Рейтинг проектных организаций, СРО-реестры, стройпорталы
- Публикации на отраслевых площадках (АСН-инфо, Строительная газета, vc.ru)
- Кейсы в соцсетях заказчиков и партнёров
- **Не покупать ссылки пачками** — в нише это быстро приводит к фильтру

### Этап 5. Контент — постоянно
- 2–4 статьи в месяц под информационные запросы
- Каждая статья ведёт на профильную услугу
- Обновлять старые статьи раз в полгода (нормативка меняется)

## 6. Что нужно от заказчика

1. **Домен и хостинг** — чтобы начать.
2. **Юридические данные**: ИНН, ОГРН, юридический адрес, членство в СРО и номер.
3. **Фактические адреса офисов** в Москве, Брянске, Орле + телефоны филиалов.
4. **Фото**: команда, офис, процесс работы, объекты (кроме визуализаций).
5. **Отзывы и рекомендательные письма** от заказчиков — скан-копии.
6. **Цены или вилки** по услугам — страницы без цен хуже конвертируют.
7. **Ник в MAX** — чтобы включить прямую кнопку мессенджера.

---

## 7. Чего делать не будем

- Не пишем «переспамленные» тексты под ключи — за это в Яндексе фильтр «Баден-Баден».
- Не делаем сотни одинаковых страниц под города с подменой названия.
- Не покупаем ссылки на биржах.
- Не ставим чужие логотипы заказчиков без письменного разрешения.
